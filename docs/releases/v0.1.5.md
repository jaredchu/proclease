ProcLease v0.1.5 is an experimental prerelease adding scoped bulk stop and
retention protection for its completion results. It also includes bounded
control exchanges and test corrections since v0.1.4. Runtime dependencies and the
Rust 1.89 minimum are unchanged.

## Bulk stop

```sh
proclease stop --all --task preview --dry-run --json
proclease stop --all --owner claude --task preview --json
```

`stop` requires either one job ID or explicit `--all`. Owner and task filters
match exactly and combine with AND. The selected IDs are fixed before shutdown;
later launches are excluded. Labels are declared metadata, not authorization to
stop another task's jobs. Unfiltered `stop --all` covers the selected registry.

The command reports every result and scan warning, continues after individual
failures, and exits nonzero for incomplete cleanup. Unknown jobs are never
signalled from saved PIDs. Supervisor requests use absolute time limits and
bounded concurrency; the existing TERM/grace/KILL lifecycle remains authoritative.
Single-ID JSON remains unchanged. `prune --json` adds a `deferred` flag.

Bulk stop protects completion records until results are captured. Normal history
collection resumes afterward; the OS releases protection if the client dies.
All clients and keepers pruning a shared state directory must include this fix.
Upgrading the CLI leaves already-running jobs under their original supervisors;
older keepers do not honor retention protection. Existing jobs are not restarted
or stopped by installation.

The suite includes 9 unit and 42 integration tests. A 105-job reproduction of the
retention race now reports all real jobs finished, with only its deliberately
unresponsive endpoint failing. See the
[verification record](https://github.com/jaredchu/proclease/blob/v0.1.5/docs/verification.md#correction-retention-race-during-bulk-stop-2026-11-07)
for evidence and limits.

## Installation

Review this release's `install.sh`, then run:

```sh
sh install.sh --skills both
proclease --version
```

The installer verifies the native archive's SHA-256 checksum and atomically
replaces the CLI without sudo or Rust. Omit `--skills both` for CLI-only
installation. Existing unrelated skill directories and links are preserved.
Restart agent sessions to discover a newly installed skill.

Source installation requires Rust 1.89 or newer:

```sh
cargo install proclease --version 0.1.5 --locked
```

Cargo installs the CLI; the portable skill is separate. The CLI-only crate has a
docs.rs overview, README and source rather than a library API. The Cargo 1.89
build-time stripping correction from v0.1.4 is retained.

## Compatibility and limits

The release workflow runs native checks and archive/installer smoke tests on
macOS ARM64/Intel and Ubuntu 22.04 ARM64/x64 (glibc). The macOS deployment minimum
is 15.0. Windows and Linux musl/Alpine binaries are not provided.

macOS binaries are not Developer ID signed or notarized. Both remain required
before stable promotion and deferred for this experimental prerelease. Checksums
verify bytes; they do not replace an authenticated publisher signature.

ProcLease manages only services launched through it. Descendants that create a
new process group can escape cleanup. Use native storage for state in VMs.
Status and log reads never renew leases. Retention protection is cooperative and
can temporarily defer collection beyond the usual newest-100/24-hour policy.
