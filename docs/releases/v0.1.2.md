ProcLease's first experimental prerelease puts explicit deadlines on development
servers and watchers started by coding agents.

- Time-limited foreground jobs with explicit extension and process-group cleanup.
- A shared user registry, bounded logs, retained retry keys and JSON output.
- Live CPU/RSS totals, adaptive terminal tables and briefly visible completions.
- Finished history retained for 24 hours or the newest 100 jobs, whichever is first.
- One portable skill for Codex and Claude Code.

## Install

Download `install.sh` from this release, review it, then run:

```sh
sh install.sh --skills both
proclease --version
```

The installer selects your native binary, verifies its SHA-256 checksum and
installs to `~/.local/bin`, without sudo or Rust. Add that directory to PATH if
needed. Existing unrelated skill folders are preserved. Omit `--skills both`
to install the CLI without linking agent skills.

Alternatively, download your platform's `.tar.gz`, verify it against
`SHA256SUMS`, and put its `proclease` executable on PATH. Each archive includes
the shared skill, README and MIT license.

## Compatibility and limits

Native tests run on the current GitHub macOS Apple Silicon runner, macOS 15 Intel,
and Ubuntu 22.04 ARM64/x64 (glibc). Both macOS binaries target macOS 15.0; an older
Apple Silicon OS is not separately runtime-tested. macOS binaries are not Developer ID signed
or notarized. Linux musl/Alpine and Windows binaries are not provided.

ProcLease manages only services launched through it. It is a supervisor, not a
sandbox: descendants that create a new process group can escape cleanup. Use
native storage for state inside a VM, not a host-shared directory. Reading status,
logs or resource usage never renews a lease. See the README for support limits.
