ProcLease v0.1.6 is an experimental prerelease adding bounded readiness checks
after launch. Runtime dependencies and the Rust 1.89 minimum are unchanged.

## Readiness checks

```sh
proclease run --task preview --ttl 30m --wait-for-port 5173 -- npm run dev
proclease run --task preview --ttl 30m --wait-for-log "ready in" --wait-timeout 1m -- npm run dev
```

`--wait-for-port` observes a TCP connection on IPv4 or IPv6 loopback;
`--wait-for-log` looks for literal text in captured output. With both flags,
both conditions must hold. The default wait is 30 seconds and the maximum is
5 minutes. Text must be 1–512 bytes without control characters.

Readiness is an observation for this invocation. It never changes the lease,
restarts the command, persists a health state or proves application health or
port ownership. A keyed retry may change its readiness options while returning
the same retained job and deadline. `--url` remains metadata.

An unmet check exits nonzero and reports the job plus its readiness result;
the job may still be running under its original lease. Keep its ID, inspect
logs, stop that job or retry the same key. Do not launch a duplicate to recover
from a readiness timeout. JSON without readiness flags keeps its existing shape.

The suite includes 14 unit and 48 integration tests, including expiry during a
wait, keyed retries, literal output and bounded log observation. See the
[README](https://github.com/jaredchu/proclease/blob/v0.1.6/README.md#readiness-wait)
and [architecture](https://github.com/jaredchu/proclease/blob/v0.1.6/docs/architecture.md#readiness-observation-v016-and-later)
for behavior and limits.

## Installation

Review this release's `install.sh`, then run:

```sh
sh install.sh --skills both
proclease --version
```

The installer verifies the native archive's SHA-256 checksum and atomically
replaces the CLI without sudo or Rust. Omit `--skills both` for CLI-only
installation. Existing unrelated skill directories and links are preserved.
Restart agent sessions to discover a newly installed skill.

Source installation requires Rust 1.89 or newer:

```sh
cargo install proclease --version 0.1.6 --locked
```

Cargo installs the CLI; the portable skill is separate. The CLI-only crate has
a docs.rs overview, README and source rather than a library API.

## Compatibility and limits

The release workflow runs native checks and archive/installer smoke tests on
macOS ARM64/Intel and Ubuntu 22.04 ARM64/x64 (glibc). The macOS deployment minimum
is 15.0. Windows and Linux musl/Alpine binaries are not provided.

macOS binaries are not Developer ID signed or notarized. Both remain required
before stable promotion and deferred for this experimental prerelease.
Checksums verify bytes; they do not replace an authenticated publisher signature.

ProcLease manages only services launched through it. Descendants that create a
new process group can escape cleanup. Upgrading the CLI leaves running jobs and
watch sessions on their original executable; installation does not restart or
stop them. Status, logs and readiness checks never renew leases. Bulk-stop
retention protection from v0.1.5 is retained and requires cooperating clients
and keepers.
